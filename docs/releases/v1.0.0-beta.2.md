# Audiora 1.0.0 Beta 2

Audiora sends your PC's audio (the whole PC or a single app) to a Sonos speaker on your local network.
This beta fixes problems found in Beta 1. It is still a beta, so it may have bugs.

## Fixed

- **Single-app streaming now recovers by itself when the source app is closed and reopened.**
  If you close the app you are streaming (for example, Brave) and open it again, Audiora attaches to the new
  process and gives the Sonos a fresh connection, just as if you had stopped and started streaming yourself.
  Your volume, your settings and "Mute PC" stay as they were. Before this fix, short audible dropouts could
  continue until you stopped and restarted streaming by hand.
  *Verified:* Brave was closed and reopened three times while streaming. Each time, playback came back without
  audible dropouts, without sound from the PC speakers and without a volume change. The event log shows each
  recovery finishing in 60–116 ms. Automated tests cover the same restart.
- **Dropout Buffer: the millisecond value now follows the slider while you drag it.**
  When you release the slider, the value shown is exactly the one you chose. The range (0–1000 ms), the
  10 ms steps, the presets and the audio behavior have not changed: the buffer still applies when streaming
  starts. *Verified* with UI Automation on the release build.
- **Event log: the automatic recovery is no longer reported as a watchdog failure.**
  When the recovery closes the previous Sonos connection, the log now says it was closed as part of the
  automatic recovery. *Verified* with an automated test and in the log of a real session.

## Downloads

| File | Use |
| --- | --- |
| `Audiora-Beta-Setup-win-x64.exe` | Installer (recommended). Installs for your user only, without administrator rights. |
| `Audiora-Beta-win-x64.zip` | Portable version. Extract it and open `Audiora\SonosFlow.exe`. |
| `SHA256SUMS.txt` | SHA-256 hashes, to check the downloads. |

**Updating from Beta 1:** close Audiora first (tray icon → Exit), then run the installer. It replaces the
installed program in `%LOCALAPPDATA%\Programs\SonosFlow`. Your settings in `%APPDATA%\SonosFlow` are kept.

## Requirements

- Windows 10 or 11, 64-bit. .NET is included, so you don't need to install it.
- A Sonos speaker on the same network as the PC, or connected to the PC's Mobile hotspot.

## Windows warning (unsigned beta)

This beta is not digitally signed, so Windows SmartScreen may show "Windows protected your PC".
To continue, choose "More info" → "Run anyway". You can first check that the file is the original
by comparing its hash with `SHA256SUMS.txt`. In PowerShell:

```powershell
Get-FileHash .\Audiora-Beta-Setup-win-x64.exe -Algorithm SHA256
```

The first time you stream, Windows Firewall may ask for permission. Allow it on private networks:
the Sonos needs to connect to the PC to receive the audio.

## Uninstall

- Installed: Settings → Apps → Installed apps → Audiora → Uninstall.
- ZIP: close Audiora (tray icon → Exit) and delete the folder.

Your settings (`%APPDATA%\SonosFlow`) and logs (`%LOCALAPPDATA%\SonosFlow`) are kept.
Delete them yourself if you want to remove everything.
